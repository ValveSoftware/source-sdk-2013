# APM (Agentic Project Management)

Purpose
- Lightweight project memory and iteration logs for this repo.
- Keep build/run notes, architecture maps, and handoff summaries in one place.

Conventions
- Keep entries concise; link to code paths when helpful.
- Prefer small, frequent notes over large walls of text.

Layout
- `apm/findings.md`: Build/run observations and TODOs.
- `apm/arch_map.md`: High-level architecture map and integration points.
- `apm/Memory/`: Optional deeper notes grouped by phases/tasks.

Start Here
- Update `apm/findings.md` with the current date and goals.
- Add or refine `apm/arch_map.md` as you explore.
