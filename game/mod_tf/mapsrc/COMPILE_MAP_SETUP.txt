Frog Bomber — why bm_arena.bsp is missing and how to fix it
=============================================================

Your console shows:
  "Frog Bomber: 15x13 on itemtest floor at ..."
That means maps/bm_arena.bsp does NOT exist. The mod is working; the dedicated map was never compiled.

This PC check (May 2026):
  - No maps/bm_arena.bsp in game/mod_tf/maps/
  - No vbsp.exe in Team Fortress 2 folder
  - No "Source SDK Base 2013 Multiplayer" in Steam (required to compile)

STEP 1 — Install compile tools (one-time)
---------------------------------------
1. Open Steam -> Library -> dropdown "Games" -> select "Tools"
2. Install: "Source SDK Base 2013 Multiplayer"
3. Wait for install to finish

STEP 2 — Compile bm_arena
-------------------------
1. Open Command Prompt or PowerShell
2. Run:
     cd <your repo>\game\mod_tf\mapsrc
     compile_bm_arena.bat
3. Success prints:
     OK: ...\game\mod_tf\maps\bm_arena.bsp

If the script says "vbsp not found", SDK is not installed or not at the default path.
Edit compile_bm_arena.bat and set SDKBIN= to your vbsp folder manually.

STEP 3 — Play
-------------
1. Quit mod_tf completely
2. ff_play bomber
3. Console should say changelevel bm_arena (not itemtest)
4. tf_bm_build_id should still be phase28-hud-floor

Hammer (optional)
-----------------
- GameDir: folder containing game/mod_tf/gameinfo.txt
- BSPDir:  game/mod_tf/maps  (must exist)
- Open:    game/mod_tf/mapsrc/bm_arena.vmf
- F9 compile, copy .bsp to game/mod_tf/maps/

Until bm_arena.bsp exists, itemtest + code-built floor is the supported fallback.
